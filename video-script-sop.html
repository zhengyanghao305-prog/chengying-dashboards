短视频脚本到底是怎么写出来的
——完整流程 + 可直接复制的提示词

我们不是靠"文笔好"在写脚本，而是跑一条固定的流水线：先用产品知识库把弹药存好，再用爆款拆解学会结构，然后让 AI 按五个角色接力出稿，最后用投放数据回填迭代。下面把每一步的流程、标准、提示词原样交出来，复制即可复用。

适用品类：家居贴纸 / 墙贴 / 贴膜 主战场：抖音短视频脚本 + 天猫&拼多多详情 更新日期：2026-09

核心心法

先讲结论。这套流程背后只有三句话，理解了这三句，后面所有环节都顺。

① 好脚本是测出来的
不是写出来的。内容成本压到几乎为零，就一次性出 5~10 版去小预算测，让数据选，不要一条磨到死。
② 写不出文案 ≠ 文笔差
是缺两步：没拆清产品卖什么（一堆参数不知道哪个是买家在意的）、没翻译成买家的话（你说"静电免胶"，买家想的是"租的房不让贴墙，有没有不留痕的"）。
③ 参数必须变成证据
卖点从"厂家话"翻译成"买家话"还不算完，每个承诺都要配一个镜头证据。比如"无胶不留印"必须拍「撕下后底材干净如新」。
一句话概括我们的活：把"产品参数"翻译成"买家下单的理由"，并且把它变成能拍出来的画面。

五个环节，每步都有固定的输入和输出。其中 Step 0 和 Step 4 最容易被跳过，但恰恰是这两步决定脚本能不能持续越写越准。

STEP 3 · 成稿

↻ 闭环：Step 4 的数据回填到 Step 0 的知识库，下一轮出稿直接站在上一轮的经验上。

0产品知识库 —— 脚本的弹药库

没有这一步，AI 只能写空话。填得越具体，尤其"劣势"和"买家常问"，脚本越能打动人。

我们现在的知识库有两层：

  • 底层原始资料：飞书《零售部产品手册》（约 2542 个节点的思维笔记）+ 店铺链接真实数据，覆盖 10 大产品系列。
  • 作战层：提炼出的《产品知识档案》与《产品痛点弹药库》，写脚本时直接读这一层，不用重复问基础信息。
知识库长什么样？每个产品固定五块：产品特性（材质/厚度/技术）、优势、劣势、客户最关心的点（用户痛点 → 对应卖点）、客服话术。写脚本时要用的就是"痛点 ↔ 卖点"的对应关系。

模板：产品知识库（每产品一份）档案原文

两种用法任选：① 直接按区块填；② 填不动就跳过，让 AI 按文末"10 个引导提问"逐个问你，你回答即可。

1爆款拆解 —— 学别人的结构

手上有拍得好的参考视频时，先把它拆成可复用的骨架和句式，再套到自己的产品上。这一步是"抄结构，不抄内容"。

1.1 先转写口播

把视频里的口播转成带时间戳的文字稿，才能逐句拆。

命令 · 音频自动转写（免装 ffmpeg）
python scripts/transcribe.py 【视频文件或目录】 -o 【输出目录】 --model small

说明：
· 首次运行会自动 pip install imageio-ffmpeg faster-whisper，并下载 whisper 模型
  （small 约 500MB），之后离线可用；ffmpeg 由 imageio-ffmpeg 自带，无需系统单独安装。
· 支持单文件或整个目录批量；已转写的文件自动跳过，加 --force 强制重跑。
· 输出同名 .txt：文件头 + [起-止秒] 文本 逐句格式，可直接用于拆解。
· 兜底方案：没有 Python 环境也不要紧，手动粘贴口播文字稿即可，拆解与生成能力不受影响。

1.2 拆解提示词档案原文

提示词 · 视频脚本拆解（把方法论整理成一键版）
你是短视频脚本拆解专家。下面给你一条参考视频的转写稿（带时间戳），
以及视频基本信息：类目【 】、时长【 】秒、平台【 】、卖的产品【 】。

请按下面的方法论，把它拆成"可复用、可迁移"的脚本资产，不要复述内容，
每一节都要落到"可直接套用的公式/句式"上：

第一步 · 结构层：按抖音带货 6 段式骨架，逐段标注它走了哪几段、每段几秒、干了什么
  ① 前3秒钩子(约10%) ② 痛点放大(约20%) ③ 产品出场(约20%)
  ④ 卖点对比(约25%) ⑤ 信任加固(约15%) ⑥ 结尾CTA(约10%)
  并判断：这条视频是完整走完 6 段，还是哪段被压缩/加强了？为什么？（结合它的品类）

第二步 · 卖点层：把它的卖点按"参数层 → 利益层"拆开
  参数层=视频里说的（规格/材质/工艺/数字）；利益层=观众为什么买单。
  每条卖点再回答三问：解决什么痛点场景？给的承诺是什么？有没有证据（实测镜头/数据/认证）？

第三步 · 钩子层：单独拎出前 3 秒的钩子句，归入下面 5 类之一并说明判断依据
  反常识/打假 · 扎心场景 · 悬念好奇 · 结果前置 · 数字冲击

第四步 · 输出七节拆解报告（一节不能漏）：
  一、视频速览（时长/类目/产品/平台/目标人群）
  二、脚本逐句拆解（表格：时间段 / 画面推测 / 口播原文 / 段落归属 / 作用）
  三、结构骨架对照（6 段式逐段标注 + 缺失或压缩判断）
  四、卖点分析（表格：参数层 / 利益层 / 痛点 / 承诺 / 证据）
  五、钩子梳理（钩子原文 / 钩子类型 / 可复用公式）
  六、可复用句式清单（分五类列出：钩子句式、演示句式、对比句式、顾虑消除句式、CTA 句式）
  七、迁移机会点（这条打法的哪几招能套到我们产品上，具体怎么套）

注意：
· 画面是推测，口播是原文，两者必须分清，不要把我的推测当事实写。
· 如果转写稿里看不出画面信息，直接列出"需要补充的画面信息"清单来问我，不要瞎编。
· 第六节和第七节是这次拆解的重点，务必写透。

1.3 拆解产出：三层 + 两张核心表

拆一条爆款，必须拆出三层东西，缺一层都算浪费素材：

层拆什么用途
① 结构层这条视频按什么骨架走（几段、每段几秒、干什么）直接照搬骨架
② 卖点层它打的是哪个痛点、怎么把参数翻译成利益学会"怎么说服"
③ 钩子层前 3 秒靠什么留住人，用的哪类钩子公式学会"怎么留人"

表 A · 标准骨架：抖音带货 6 段式

段落作用时长占比典型动作 / 句式
① 前 3 秒钩子给结果或冲突，留住划走的手指10%一句反常识 / 扎心场景 / 悬念
② 痛点放大让观众代入"说的就是我"20%具体生活场景 + 情绪
③ 产品出场亮出"这是什么、怎么用"20%演示核心动作（一撕 / 一贴 / 一擦）
④ 卖点对比打消顾虑，建立差异25%无胶 vs 带胶、可撕 vs 难清
⑤ 信任加固给证据 / 人群背书15%认证 / 适配面 / 实测 / 数据
⑥ 结尾 CTA给行动指令10%小黄车 / 评论区扣关键词

时长占比是经验值，可上下浮动 5%。拆解时要判断：这条视频完整走完 6 段了吗？哪段缺失 / 压缩 / 拉长？为什么？

表 B · 钩子的 5 种类型（前 3 秒靠什么留人）

钩子类型公式例子（我们的品类）
反常识 / 打假「别再用 XX 了」/「XX 其实都是坑」「带胶的窗花撕下来全是印」
扎心场景「[人群]，[扎心场景]？」「出租屋的墙，你是不是不敢动？」
悬念 / 好奇「[结果]，原来只要 XX」「贴一年的墙，撕下来像新的」
结果前置直接给终态画面 + 一句话「不刷漆，也能让墙焕然一新」
数字冲击用数字制造反差「一天才几毛钱，换你一年不用擦墙」

表 C · 可复用句式清单（拆解时必抽）

  • 钩子句式：别再[错误做法]了，试试[产品]
  • 演示句式：往[位置]上一[贴/按]，[不用 X] 就[结果]
  • 对比句式：不像[竞品]，[竞品缺点]，我们[你的差异]
  • 顾虑消除句式：很多人怕[顾虑]，其实[解决方式]
  • CTA 句式：评论区扣[关键词]，我帮你[动作]
两个坑别踩：① 画面和口播要分开——口播是转写稿（原文），画面是推测，必须标注清楚，别把推测当事实。② 缺画面信息就直接问"前 3 秒画面是什么"，不要瞎编镜头。

2五角色接力 —— 核心出稿环节

这是整套流程里最关键的一段提示词。原理是把"写文案"拆成五个专业工种，让 AI 一次只干一件事，避免一锅烩出平庸稿。

角色职责输出
① 卖点分析师把产品知识库的卖点拆成「参数层 + 利益层」卖点清单（参数 → 利益）
② 人群分析师定义 3 类最可能买单的人群画像人群卡片（身份 / 时刻 / 怕什么 / 被什么打动）
③ 文案策划师卖点逐条翻译成"买家听得懂的话"买点清单（≤5 条，口语化）
④ 评审专家用转化标准审稿，打回不过关的审稿意见 + 打回理由
⑤ 优化专家输出最终可用稿，按标准格式脚本策划（多版）

主提示词（复制这段直接发给 AI）档案原文

下面这段直接发给 AI（豆包 / Kimi / DeepSeek / 通义都行，建议用强的模型），然后按里面要求一步步跑。一次只跑一个产品。换产品时只换开头的产品名和素材卡，角色分工不用改。

提示词 ① · 五角色接力出稿（核心）
你是我的电商文案团队，下面要服务一个家居贴纸/墙贴卖家，产品是【贴产品名称】。
请以五个角色分工，严格按顺序接力，每一轮只输出当前角色的成果，不要一次性全给：

角色①卖点分析师：根据我提供的素材卡，把所有卖点拆出来，分两层列：
  - "参数层"（规格/材质/工艺/数字）
  - "利益层"（这个参数对买家意味着什么）
  如果素材卡信息不足，直接列出"需要补的信息"问题清单，不要瞎编卖点。

角色②人群分析师：根据产品和使用场景，定义 3 类最可能买单的人群画像。
  每类人写清楚：身份场景、ta 在什么时刻想买这个、ta 最怕什么（顾虑）、ta 会被哪句话打动。
  如果分不清，给出你最可能的 1-2 类，并说明为什么。

角色③文案策划师：把素材卡里的"卖点"逐条翻译成"买家听得懂的话"（痛点→场景→承诺）。
  参考句式：参数"静电免胶" → 买家话"租房也能贴，撕下来不留印，房东检查不扣钱"
  输出"买点清单"（5 条以内），每条一句话，口语化。

角色④评审专家：拿转化标准审稿：
  - 3 秒内能不能看懂"这是什么、关我什么事"
  - 有没有具体场景让买家代入
  - 有没有消除顾虑（留痕？难贴？会掉？尺寸？）
  - 有没有行动指令（下单 / 点关注 / 看详情）
  把不过关的买点打回去重写，给出理由。

角色⑤优化专家：输出最终可用稿，严格按出口格式给：
  【出口A 抖音脚本】给 2 版，每版含：前 3 秒钩子 / 画面建议 / 口播文案 / 字幕关键词 / 结尾 CTA
  【出口B 电商详情文案】给 1 套，含：标题关键词组合 / 首图卖点字 / 详情页 5 条卖点小标题+正文 / 规格说明提醒

（每次换产品，把【产品素材卡】换成新卡，上面这段角色分工不用改。
  想更针对某个平台，就加一句："本次只要出口A，参考平台：抖音，人群偏 XX。"）

配套用法：跑之前先把 Step 0 的【产品知识库 / 素材卡】内容粘贴在后面一起发给它。

评审专家的 4 条硬标准（转化四问）

① 3 秒懂吗
3 秒内能不能看懂"这是什么、关我什么事"
② 能代入吗
有没有具体场景让买家代入（不是抽象形容词）
③ 顾虑消了吗
留痕？难贴？会掉？尺寸？——买家怕的四个问题有没有正面回答
④ 有行动指令吗
下单 / 点关注 / 看详情 / 评论区扣关键词

可选增强：一次出多版测款脚本整理版

如果要批量测款（默认动作就是出 5~10 版，别磨一条），在五角色之后追加这段：

提示词 ② · 批量出多版测款脚本
基于上面的买点清单和人群卡片，一次性给我【5~10】版可开拍的抖音脚本。

要求：
1. 每版用不同的钩子类型（反常识/打假、扎心场景、悬念好奇、结果前置、数字冲击），
   并在版本标题里标明这版是"什么钩子 + 打哪类人群"。
2. 每版严格按这个格式输出：
   【版本 N：钩子类型名】
   - 目标人群：
   - 前 3 秒钩子（口播原文）：
   - 前 3 秒画面：
   - 结构：①钩子(0-x s) ②痛点(x-x s) ③产品出场 ④卖点对比 ⑤信任加固 ⑥CTA
   - 口播全文（按约 5 字/秒估算，卡着时间轴走）：
   - 字幕关键词：
   - 结尾 CTA：
   - 黄金镜头（必拍）：
   - 这版靠什么留人 / 靠什么转化：
3. 黄金镜头是把卖点从"参数"变成"证据"的关键画面，所有版本都要保留。
   例如静电类产品必拍「撕下后底材干净如新」。
4. 价格统一不展示客单价区间，改用冲击话术：
   "一天才几毛钱，换你 XX"。

3成稿格式 —— 交出去的稿子长什么样

格式统一，拍摄和剪辑才能直接照着执行。我们目前用两种格式，取决于脚本要不要拆人群。

3.1 单版脚本格式（每版含 8 项）

模板 · 标准脚本策划格式
【版本 N：钩子类型名】
- 目标人群：
- 前 3 秒钩子（口播原文）：
- 前 3 秒画面：
- 结构：①钩子(0-x s) ②痛点(x-x s) ③产品出场 ④卖点对比 ⑤信任加固 ⑥CTA
- 口播全文（按约 5 字/秒估算，卡时间轴）：
- 字幕关键词：
- 结尾 CTA：小黄车 / 评论区扣「关键词」
- 黄金镜头（必拍）：

3.2 多人版脚本格式（画面固定，只换口播）

这是我们目前最常用的方式：画面脚本拍一条，口播配多版，一条素材变成多条测试内容。

模板 · 固定画面 + 多版口播
一、拍摄脚本（固定 · XX 秒）
| 段 | 时间轴 | 画面建议 | 情绪 |

二、口播文案（只换这段，画面不变）
### 版本 1 · 【人群 A】
- ① 痛点（0-Xs）：「……」
- ② 卖点+买点（X-Xs）：「……」
- ③ 转化（X-Xs）：「……」

### 版本 2 · 【人群 B】
……

三、说明
- 一条画面拍完，配 N 段口播 = N 条测试素材，一条打"XX"，一条打"XX"。
- 口播按约 5 字/秒估算；主播语速偏慢就适当留白，别硬压。
- 必拍黄金镜头：① …… ② ……（无胶证据）③ 对比镜头。
为什么口播按「约 5 字/秒」卡？这是实测下来的中文口播舒适语速。先把画面时长定死（比如 25 秒 → 约 125 字），再写口播，就不会出现"稿子太长念不完"或"画面空转"的问题。

3.3 线上出稿工具用的分镜表格式

内部「文案智能体」页面（workbench 里的 copywriter-ai.html）已经把这套流程做成了表单：填知识库 → 选投放平台和脚本数量 → 直接出稿。它输出的短视频脚本是六段分镜表：

镜号 / 时间 / 段落 / 景别运镜 / 画面内容 / 口播 / 字幕

段数、时长、环节名称由 AI 根据产品和平台自由编排，只锁定这张表的格式。默认脚本时长 15-30 秒。

4数据回填 —— 让脚本越写越准

这一步最容易跳过，但它是整套流程"能持续变好"的原因。发布/上架后，回填两个数到知识库。

数据说明什么问题去改哪里
点击率 CTR 低 钩子 / 首图 / 标题没抓人，人根本点不进来 改出口 A 的前 3 秒钩子、首帧画面；电商端改标题关键词和首图卖点字
转化率 CVR 低 人进来了但不买，说服逻辑不够 补「顾虑消除」和「行动指令」；电商端改详情页说服逻辑
为什么能无限测：内容生产成本压到几乎为零，于是可以批量出、批量测，让数据来选版本。每个产品的知识库都值得跑 5 版去测一遍。别在一条稿子上反复磨。
投放前
同一产品出 5~10 版（不同钩子 × 不同人群），小预算测
投放中
盯 CTR / CVR 两个数，判断是"钩子问题"还是"说服问题"
投放后
把这轮结论回填到知识库，下一轮直接站在经验上出稿

实战样例：真实产出的脚本

下面是按这套流程做出来的真实交付稿，可以直观看到"流程 → 成稿"的结果。

样例一 · 点断撕厨房防油贴纸（25 秒 · 固定画面 + 2 版口播）

骨架（3 段）：① 痛点·留人（0-7s）→ ② 卖点+买点（7-19s）★ → ③ 转化（19-25s）

拍摄脚本（固定，一条画面拍完）全片 25 秒 · 口播约 125 字
① 0-7s灶台后墙油渍满墙、发黄，抹布擦一遍两遍三遍还是花的、油光黏手，越擦越花。（情绪：烦躁）
② 7-19s ★展示一卷 → 沿虚线"啪"撕一张 → 往墙上一按就吸住（无胶）→ 油点一擦即净 → 一卷好几张不用裁剪；脏了撕下来换一张，墙还是干净的。
③ 19-25s多款式展示 + 结尾 CTA。
CTA左下角小黄车，30/45/60cm 三种宽幅自己挑；拿不准尺寸评论区扣"尺寸"。
口播版本 1 · 租房上班族
①0-7s「上了一天班回到家，厨房那面墙油得发黄，擦三遍还是花的，手黏糊糊的——那一刻真的不想干了。」
②7-19s「后来我用上这个防油贴，一卷好几张，一撕一张按墙就吸住，油一擦就没，脏了撕下来换张新的，墙永远干干净净；再也不用下班了还跟这面墙较劲。」
③19-25s「租房党都懂，退租也不怕墙脏扣押金。一天才几毛钱，厨房清清爽爽，左下角自己挑。」
口播版本 2 · 中老年 + 家庭主妇
①0-7s「顿顿开火，灶台后墙油腻发黄，一遍一遍擦还是花的，弯着腰、手黏糊糊，心里是真烦。」
②7-19s「后来用上这个防油贴，一卷好几张，一撕一张按上就吸住，油一擦就净，脏了撕下来换新，墙一点不伤；再不用爬高弯腰地去擦了。」
③19-25s「过日子图个省心，一天才几毛钱，省下的都是工夫。灶台瓷砖玻璃都能贴，左下角拍。」

必拍黄金镜头：① 擦不掉的油墙 ② 撕下旧张露出白净墙（无胶证据）③ 一卷 vs 带胶单张对比。

样例二 · 静电新年玻璃贴纸（22 秒 · 打假式）

骨架（5 段）：① 痛点·放大（0-3s）→ ② 打假（3-8s）→ ③ 展示（8-13s）★ → ④ 动作效果（13-18s）→ ⑤ 互动（18-22s）

拍摄脚本（固定）全片 22 秒 · 口播约 110 字
① 0-3s镜头怼玻璃上旧贴撕下的色印——擦不掉、铲不净、晒过更深。　字幕：别再去贴那些假的静电窗贴啦
② 3-8s主播拿着我们的产品。　字幕：看好了，真正的静电无胶窗贴
③ 8-13s ★产品细节特写——好看的款式、高饱和的颜色；演示撕下窗贴特写——玻璃无胶印、不留色、不沾手。
④ 13-18s喷水往玻璃一贴、卡片一刮就服帖；贴一整年撕下玻璃如新。　字幕：真无胶 · 贴一年零留色
⑤ 18-22s展示窗贴贴在玻璃上的整体效果。　字幕：大家觉得这个咋样？评论区告诉我

口播原文（1 版 · 约 110 字 / 22 秒）

①0-3s「旧窗贴撕下这圈色印，擦不掉、铲不净。」
②3-8s「看好了，真正的静电无胶窗贴——我们才真无胶、真不留胶。」
③8-13s「你看这羊年新款，颜色多正，撕下玻璃无胶印、不留色、不沾手。」
④13-18s「喷点水一贴、卡片一刮就服帖，贴一整年撕下如新。」
⑤18-22s「大家觉得咋样？想要哪个花色，评论区告诉我。」

三条证据镜头：① 旧贴色印（打假靶子）② 撕下零胶印 / 不留色（核心证据）③ 喷水→卡片一刮→服帖（动作效果）。

从上面两个样例能看出什么：骨架不同（3 段 vs 5 段），但底层逻辑一致——痛点 → 产品 → 证据 → 转化。骨架是按产品特性定的：防油贴"擦墙累"是主痛点，所以痛点段拉到 7 秒；玻璃贴要对打"假静电窗贴"，所以单开一个"打假"段。

调性铁律

这些是实际跑下来反复打磨出来的规则，比方法论更容易踩坑。

关于口播

  • 口播要有情绪、讲代入感，不是在背产品参数。先讲"人的感受"，产品只作为"后来我怎么解决了"轻轻带过。
  • 按约 5 字/秒卡时间轴。先把画面时长定死，再写口播；语速偏慢就留白，别硬压。
  • 不展示客单价区间，统一改用冲击话术："一天才几毛钱，换你不用搭理厨房 / 窗户"。
  • 版本宁少勿多，但测款要 5~10 版——这是两件事：给客户看要精，投出去测要多。

关于结构与分工

  • 画面骨架由人定死，口播换人群。骨架（时间轴 / 镜头）由业务方固定不可改，AI 只在口播上做人群切换。最常用
  • 人群话术分工：年轻人强调"省事 + 不担责"（租房、退租、房东）；中年强调"省心 + 对家人负责"（当家的、体面、环保无味）。
  • 同一卖点对不同人群要说两种话。例："静电免胶" → 年轻版"退租一撕就走，房东不扣押金"；中年版"不伤墙不留印，家里墙面好好的"。

关于产品信息

  • 参数必须变证据。静电类产品所有版本都要保留「撕下后底材干净如新」这个黄金镜头。
  • 劣势要主动化解，不要藏。比如静电产品"高温容易起鼓"，脚本里主动说清楚或给实测画面，别让买家在评论区问出来。
  • AI 不许编。素材卡里没有的信息，要求 AI 列"需要补的信息"清单，用【待核实】标注，不能造假。
  • 款式归类由拍摄方定。脚本里统称"节庆款 / 新年款"，具体哪张图配哪套，拍摄时自行配对。

分平台口味差异

出口一句话核心容易踩的坑
抖音脚本前 3 秒给"结果或冲突"，别铺垫口播像念说明书
天猫 / 拼多多详情每条卖点 = 一个场景 + 一个承诺 + 一个证据堆参数，没有画面感
小红书收藏欲 > 购买欲，笔记要让人想存太广告，像卖家秀

标题和卖点分开：天猫拼多多流量贵，标题堆的是"搜索词"，卖点是给"详情页"的。标题负责被搜到，详情负责让下单。
