ⓘ 指标口径 · 每列逻辑 + 可换算派生指标

原始列逻辑（表内行=日期，每组列=一个链接：我方 or 竞品）：

  • 访客 = 当日进店人数；支付单量 = 当日成交订单数
  • 付费点击量 / 付费支付单量 = 付费推广带来的点击数 / 成交数（表内暂缺，明日补全）
  • 点击率 = 点击÷曝光 · 加购率 / 转化率 = 加购人数 / 支付买家数 ÷ 访客（生意参谋口径：转化率×访客 ≈ 支付买家数，与支付单量不同量纲——一人可多单，勿拿 单量÷访客 反推转化率）
  • 点击单价 = 付费花费÷付费点击 · ROI = 成交金额÷付费花费
  • 免费搜索 / 免费推荐 / 免费其他占比 = 免费流量三个来源各占总访客的比例，三项之和 = 免费流量占比，余下即为付费流量占比
  • -区间 列 = 运营登记的区间源数据（如 100~250 / 5%~7.5%），脚本取区间中值作估算快照

可换算 / 派生指标：

  • 免费流量占比 = 免费搜索+免费推荐+免费其他；付费流量占比 = 1−免费流量占比（我方≈46%，头部竞品≈2%）
  • 免费订单占比 = 1−付费支付单量÷支付单量 ⏳　·　付费订单占比 = 付费支付单量÷支付单量 ⏳（表格两列已就位，付费列补全后自动出数，与竞品同口径横比）
  • 付费点击转化率 = 付费支付单量÷付费点击量 ⏳　·　客单价 AOV ≈ ROI×点击单价×付费点击量÷支付单量 ⏳　·　UV价值 = 支付单量×客单价÷访客 ⏳
  • 市占率 = 我方单量÷(我方+全部竞品单量)　·　强弱雷达每维按 0~100 相对归一，可直接横比

⏳ 依赖「付费点击量 / 付费支付单量」，明日补全后「免费/付费订单占比」两列会自动出数并参与强弱对比，无需再改。
