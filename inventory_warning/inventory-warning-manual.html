📦 库存预警 & 备货单 · 极简使用说明书

给老板 / 仓库 / 运营看的一页纸 ｜ 系统每天自动跑，你只管看卡 + 点按钮

一、它每天做什么

每天早上，系统自动完成：

  1. 拉飞书里的 库存 和 销量
  2. 算每个编码 7 天后会不会断货
  3. 该备货的自动写进 《备货单》
  4. 给你（Sunny）飞书私聊推一张 汇总卡

二、你收到的飞书卡怎么看

KPI监控编码数 / 紧急 / 预警 / 备货件数
🔥爆单提示（近期突然放量）
🚚在途跟进（在产 / 超期催单）
📉下架库存预警（可发<10）
  • 最需备货家族 Top8（可展开）：按产品排，先看这里
  • 两个按钮： 📦 查看备货单 打开飞书《备货单》表 ｜ 📊 查看预警明细 打开预警明细表

三、你在《备货单》里要做的三件事

操作怎么做效果
开单生产 点某行的「一键开单」按钮 自动建工单 + 状态变「已开单」
这轮不备 点「暂不备货」按钮 状态变「暂不备货」；库存还缺的话第二天会重新出现
取消这单 手动把状态改成「取消备货」 人工取消；第二天若库存仍缺会重新被推荐（另起一行）
工单做完入库后，系统自动把状态回写为「已完成」，不用你管。

四、状态颜色速记

🟡 待备货 系统刚算出来，等你开单 🔵 已开单 已下单生产 ⚪ 暂不备货 这轮先不备（会再来） ⚫ 取消备货 你主动取消（会再来） 🟢 已完成 入库搞定

五、两个要知道的坑

1. 「取消备货 / 暂不备货」不是永久屏蔽
只要库存还缺，第二天系统还会把它重新推出来。想永久不备，得从根上解决（清库存 / 下架类型，或真把库存补上）。
2. 删除工单后状态不会自动变
删了跟进表里的工单，备货单状态要你手动改成「取消备货」（或等飞书原生自动化生效），系统本机不再自动回退。

六、一句话总结

看卡 → 开单就点按钮 → 不备就点暂不备货 → 剩下的系统自己算、自己跟踪。

详细算法（备货数公式 / 分级口径 / 状态机）见《库存预警本机自动化-生成逻辑整理.md》。
